# Windows 0.1.4：统一验收说明

本版替代尚未执行的 0.1.3 验收，不增加逐项测试轮次。保留旧包，退出旧版后使用独立的 0.1.4 目录；配置和历史沿用。

当前先完成后台开发检查，不要求你立即测试。之后方便进行完整验收时，集中做一次截图整理工作即可：

1. 运行包内 BACKGROUND-CHECK.cmd，记录 BACKGROUND-CHECK.log；它不启动托盘、不接管键鼠。若失败停止本轮，一次反馈日志。
2. 打开 0.1.4，截取本来要用于文档或消息草稿的一组图片，包含连续截图。使用 B 和 C 选择、预览并拖入同一个草稿，无需发送；按平时速度在托盘展开及新图入场时选图，应该立即选到当前可见的图片。B 的虚框表示选中项，彩色写入指针表示下一张的落点，两者独立。
3. 在这段工作中切换 A/B/C、关闭并重新开启应用动效。如果方便，可提前打开 Windows 动画设置，在动效进行中关闭系统动画，观察没有冻结粒子或 READ/WRITE 残留；不必反复追赶短时序。保持个人辅助功能偏好优先。
4. 最后收起再展开，确认草稿里的图片是所选图片。统一反馈是否有误选、无响应、卡顿或残留；如有问题，附日志和一次设置中的动效诊断。

无需人为按住图片等待淘汰，也无需逐格检查写指针：这些已加入自动回归。预计完整工作约 10–15 分钟，仅为估计。遇到错误停止新版，不循环重试；旧包可回退，无需删除配置或截图。

Windows WPF 离屏回归已经编译，但当前 Mac 无法执行；真实点击、外部拖放、系统动画通知及目标机器流畅度仍未实机确认。测试包未签名，接入落盘图片，仍按鼠标所在显示器展开。
