# Windows 0.1.5：一次完整验收

本版合并此前尚未完成的验收，不要求现在逐项测试。Mac 上已运行核心回归并完成 Windows x64 交叉编译；WPF 离屏检查已加入包内，但只能在 Windows 执行，不计作已通过。

方便时，用一次实际截图整理工作集中确认即可：

1. 退出旧版，解压完整 0.1.5 包，运行 `BACKGROUND-CHECK.cmd`。它不打开托盘、不截图或接管键鼠；若失败，停止并统一反馈 `BACKGROUND-CHECK.log`。
2. 打开应用，截取一组用于同一文档或消息草稿的图片，包含横图、竖长图和连续截图。在展开及新图入场时选择、预览并拖入草稿，无需发送。
3. 在同一次工作中切换 A/B/C 和中英文：A 的尺寸留在所属列内；B 时间及读写状态沿卡片右侧对齐；C 摘要居中，展开标签不互相挤压。顺便关闭、恢复界面动效；不必追赶短暂动画或重复已通过的操作。
4. 确认草稿图片与选择一致，统一反馈是否有误选、无响应、遮挡、粒子残留或明显偏移。如遇异常，附后台日志和设置中的动效诊断。

Windows 窗口/字体实际显示、100%/150%/200% 混合缩放、真实拖放和系统动画通知尚无本机执行证据；这些不是交叉编译可以证明的结果。已有配置和截图沿用，不需重新配置。保留旧版 ZIP 以便回退，勿删除个人截图或设置。
