# Windows 0.1.3：一次完整验收

目标：整理一组用于文档或消息草稿的截图，确认连续收纳时选图准确、样式切换顺畅、关闭动效后画面干净。一次预留约 10–15 分钟（估计），全部完成或遇到首个阻断问题后统一反馈，不需要逐项回到聊天。

## 一次准备

保留旧版 0.1.2 文件夹，退出旧版。将 0.1.3 解压到独立目录；身份、配置和历史目录沿用，不必重新设置。先双击包内 `BACKGROUND-CHECK.cmd`，查看生成的 `BACKGROUND-CHECK.log` 最后一行是否为 PASS。此检查使用临时合成图片，不打开托盘、不操作鼠标键盘、不读取你的截图，不需安装 SDK。若出现 FAIL 或没有日志，停止本轮并一次性反馈日志，不反复尝试。

这是本轮唯一需要在 Windows 上补跑的自动检查：Mac 无法执行 WPF。它覆盖真实托盘绘制中的连续接收、过期选择、C 飞入命中、样式切换、应用与模拟系统动效关闭、重新开启。它不替代真实的系统设置通知、鼠标事件、显示器流畅度和外部应用拖放。

通过后运行 `Jieliu.exe`，设置窗口确认 0.1.3。只核对截图工具自动保存目录与接入目录一致。开始时记录应用动效、Windows 系统动画和自动收起的原设置，结束时恢复。为方便观察残留，可暂时关闭自动收起；本轮不会自动接管前台。

## 一段完整的截图整理工作

1. **C 收图与选图。** 选择 C，截取几张有实际用途、内容容易分辨的图片，包含两张连续截图。在新图飞入且与旧图重叠时，按平时速度点击或双击新图：选中或预览应对应眼前的新图。再从已落位的图片中多选，将其拖进常用文档或消息草稿，核对内容，无需发送。无需刻意复现“按住旧图再按 Shift”的极短时序，该边界由自动回归负责。

2. **继续收图并切换样式。** 收集同一工作所需的后续图片，使本轮累计至少 9 张，覆盖容量淘汰。途中从 C 切到 B，再短暂切 A、回到 B；可以在新图入场尚未结束时切换。应保留最近 8 张，旧动效不跨样式残留，预览和拖出仍对应所选图片。

3. **这段工作中暂时停止动效。** 在 B 继续收图、粒子尚在运动时，关闭应用“界面动效”，新旧图应直接稳定，不残留 READ/WRITE 或粒子；再开启应用动效。随后保持托盘展开，正常再截一张，在其动效尚未结束时关闭 Windows“辅助功能 → 视觉效果 → 动画效果”。可以提前将系统设置放在旁边，方便完成；若没赶上，记录“系统切换未覆盖动画中”，不反复追赶短时序。关闭后应立即稳定，无冻结浮卡或读写提示，重新开启后不会重播已经取消的旧动画。因辅助需求不适合开启系统动画时，保留个人偏好并注明本段未测即可。

4. **收尾。** 从最近图片里选出最终要用的几张，预览并拖入同一份工作文档或草稿。收起再展开托盘，画面应干净；恢复自己的动效与自动收起偏好，完成整理。

本次不重复已通过的普通删除、文件夹创建或语言切换，也不要求逐帧核对 HTML。多屏和缩放只使用平时已有环境，不增加设备配置任务。

## 最后一次反馈

- 整理任务是否完成；是否选错/拖错图、卡住或残留，以及大致发生在上述哪段。
- 附 `BACKGROUND-CHECK.log`；如有视觉异常，再从设置导出一次动效诊断。只有难以描述时才补短录屏，避开私人内容。
- 注明 Windows 系统动画切换是否覆盖了动画进行中，以及使用的缩放/显示器环境即可。

遇到异常退出、持续卡住或误选，停止新版并一次反馈，不循环重试；退出新版后运行保留的旧版可回退，不删除截图与配置。

## 已知边界

这是未签名的 Windows x64 测试包。仅接入落盘图片；新截图仍在鼠标所在屏幕展开。入场从托盘附近开始，尚无可靠原截图坐标。后台离屏检查不能证明真实窗口焦点、外部拖放和流畅度已通过；这些由上述完整工作统一确认。
