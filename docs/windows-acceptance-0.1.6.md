# Windows 0.1.6：一次完整验收

本版合并此前尚未完成的 Windows 验收，不增加逐项代测。Mac 上已运行跨平台核心回归、完成 Windows x64 交叉编译；Windows WPF 的解码、绘制和交互检查已包含在包内，但需在 Windows 执行，不能视为已经通过。

方便时，只需用一段实际截图整理工作集中确认：

1. 退出旧版，解压完整 0.1.6 文件夹，先运行 `BACKGROUND-CHECK.cmd`。它不显示托盘、不截图或接管键鼠，自动检查坏图恢复、原生 PNG 缩略尺寸、A/B/C 绘制/命中、动效取消及布局对齐。若失败，停止并统一反馈 `BACKGROUND-CHECK.log`，无需手工制造坏图或逐项复测。
2. 打开应用，收集一组要放入同一文档或消息草稿的截图，包含横图、窄长图和连续截图。按平时速度在展开和新图入场时选择、预览、拖入草稿，无需发送；确认原图清晰度与选择一致。
3. 在这段工作中切换 A/B/C、中英文，关闭并恢复界面动效。顺便用 Shift+方向键连续扩选，确认能继续移动。观察 A/B/C 的标签不挤压，B 时间/状态靠右，C 摘要居中，动画收尾没有跳位或粒子残留。
4. 最后统一反馈是否有不接收截图、误选、无响应、遮挡、明显卡顿或拖放错误。异常时附后台日志及设置中的动效诊断；不用追赶短暂时序或重复已通过操作。

仍需目标机器证据的部分：Windows WPF 实际解码与字体显示、真实窗口/焦点、外部应用拖放、系统动画通知和多屏混合缩放。当前没有 Windows 实机结果，不承诺已验证流畅度或实际内存峰值。设置、历史和截图目录沿用；保留旧版 ZIP 以便回退。
