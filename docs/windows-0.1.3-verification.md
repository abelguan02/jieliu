# Windows 0.1.3 修复与验证记录

日期：2026-10-16。针对 0.1.2 审查的三个问题完成修复，保留旧包，提供独立 0.1.3 包。没有启动桌面窗口、操纵鼠标键盘、修改系统动画设置或上传 GitHub。

## 修复结果

- **连续截图与选择：** 被淘汰的按下目标和待松开选择立即取消，过期目标在提交选择时再次拒绝；范围选择不会再用不存在的索引。样式切换会取消未完成的鼠标选择，并清除旧命中缓存。图片在首次绘制前被淘汰时，也清理其入场记录。
- **C 飞入命中：** 飞入图片与静止图片按实际绘制顺序参与四边形命中，点击/预览/拖动命中眼前的飞入图片，不再穿透到其下方旧图。
- **关闭动效：** 窗口订阅系统动画设置变化并在关闭时注销；应用关闭、系统关闭、已排队重绘都走有效动效策略。取消入场、移出、读写提示、归档脉冲和布局过渡，悬停/展开直接收敛到终态，停止动效刷新。重新开启不会回放取消的效果。

## 已执行

- `Jieliu.Checks` 全部通过，包含新增过期目标在无修饰键、Ctrl、Shift、Ctrl+Shift 下的拒绝，保留有效选择，失效 anchor 回退，多选、范围选择与单选回归；原几何/粒子/历史/文件监听检查也通过。
- 在临时副本故意反转“过期目标拒绝”条件，新测试按预期在 `Evicted target must be rejected` 失败；副本已恢复，应用源码没有被该实验改动。
- Windows 项目交叉编译及最终 win-x64 自包含发布成功。依赖缓存带有 NU1900 在线漏洞数据获取警告；未将在线依赖漏洞审计记为通过。
- 差异空白检查通过（PowerShell 文件的 Git CRLF 提示不是编译错误）。
- 最终 ZIP 完整性检查通过，入口确认为 Windows x86-64 PE 程序，包内包含验收卡和离屏检查入口。

## 已编写并编译、未执行的 Windows 自动回归

`--render-check` 新增真实 `TraySurface` 的离屏状态和绘制回归：C 飞入重叠命中、按住目标被淘汰、切换样式取消待提交选择、A/B/C 入场和移出中分别关闭应用/模拟系统动画、关闭后的静态像素一致性、重新开启不回放、32 次接收与切换交错，以及 24 次来图在首次绘制前完成的突发场景。使用可控时钟，无需人工追赶短动画时序。

这些回归已纳入原 Windows 检查脚本；便携包内 `BACKGROUND-CHECK.cmd` 可不依赖 SDK 运行并产生日志。当前只有 Mac，无法执行 WPF；因此没有宣称该自动回归已通过，也没有宣称实际系统通知或 Windows 体验已经验证。
