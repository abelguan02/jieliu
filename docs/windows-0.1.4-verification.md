# Windows 0.1.4：可见图片的即时选择

修复 B 入场动画和托盘展开时点不动的问题。B 的目标槽位在动画期间可选择；浮卡扫描、移动粒子及写入图像按实际绘制区域参与命中，并按显示层次优先选中顶部图片。选中时立即在槽位显示虚框。粒子的绘制与命中共用同一个位置计算，避免两套坐标漂移。

托盘中的图片开始显示后即可选择，不再等待完全展开。点击坐标会转换到当帧的内容位置，窗口外及未显示的内容不能选中；展开期间的标题按钮也使用相同的坐标转换。折叠胶囊仍仅负责展开。

## 缓存区写入顺序

用户的理解正确：B 从左到右依次写入，写到第 5 格后，即使选中第 2 格，下一张仍写入第 6 格；第 8 格之后回到第 1 格。选中虚框不会移动写入指针。覆盖托盘记录不删除归档文件。手动移出形成空格时也不改变写指针，并非总是优先填空格。
