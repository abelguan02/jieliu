# 双端 Pin 集中验收

对应 `codex/pin-shared-ci` 源码，容量固定 8 格。本轮未更新安装包，不能用旧的 Mac 1.0.5 / Windows 0.1.6 安装包验收 Pin。应在后续打包、核对安装版本后执行；任何启动窗口、切换应用或接管输入均先取得用户当时的空闲确认。

两端分别执行以下一次完整流程，记录通过、失败或未验证；使用中性测试截图，不使用私人素材。

1. 使用 B 样式生成 8 张测试截图。选两张，右键「固定」；右键已选项应保留多选，右键另一张应切换目标。按 P 验证固定和取消固定，混合选择执行固定。菜单打开期间托盘不应自动收起。
2. 固定两张后连续截图超过 8 张，确认它们仍在原槽，其他槽位更新。主动移出一个未固定项，再截图，应先填该空槽，原文件仍在归档文件夹。B 的下一写入标记不能指向固定项。
3. 全选并固定 8 格，再截图：文件夹中有新文件，托盘原有 8 张不变，出现未入托盘提示且没有虚假入槽动画。取消一张的固定后再截图，应恢复入槽。
4. 切换 A/B/C，确认图钉清晰、选择与点击位置正确，固定图片仍可复制、拖出原图和预览。Mac 使用 ⌘C，Windows 使用 Ctrl+C。复制与拖放目标选一个日常使用的应用。
5. 正常退出并重开，确认固定状态与槽位恢复。主动移出一张固定项，确认归档原文件保留，随后截图能填入空槽。
6. 切换中英文、关闭动效、使用仅菜单栏/系统托盘入口，重复一次满槽提示；有多屏时确认提示出现在预期屏幕且不抢当前应用焦点。没有对应设备的项目明确标记未验证。

验收结束后恢复测试前的历史、偏好与测试文件状态，并告知用户可以恢复操作。不得将离屏测试通过记为上述系统集成已通过。
