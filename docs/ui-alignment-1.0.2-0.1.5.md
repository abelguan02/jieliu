# 视觉对齐修正：Mac 1.0.2 / Windows 0.1.5

保留现有配色、取景框胶囊、A 标尺、B 环形缓冲与 C 投影图层风格。仅调整排布、文字锚点与必要的裁切；截图接入、文件归档、选择规则与设置位置保持原有契约。

## 两端改动

- B：时间、READ/WRITE 与空状态统一靠缩略图右边缘，使用实际字体宽度计算位置。
- C：摘要按实际文字宽度居中；标签根据当前展开间距限制宽度，不再相互覆盖。Mac 根据可用空间使用完整标签或仅显示时间；Windows 在入场卡片落定后显示标签，避免飞行中的标签挤到已有标签。两端长文字均在所属标签内裁切。
- A：Mac 把尺寸与时间标签计入每张图占位，长尺寸优先缩略，时间保持右对齐。Windows 原有固定列保留，尺寸文字限制在所属列内。
- Mac A：标尺刻度与悬停高亮避开归档按钮，防止背景内容透出或盖住按钮；Mac C 的归档按钮移到顶部标题行，避免八图层展开时与图片相撞。
